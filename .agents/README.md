# Project skills

Installed locally with `npx skills add <source> --skill <names> --agent codex -y`.
Source paths and content hashes are recorded in `../skills-lock.json`.
Use `npx skills list` to inspect and `npx skills experimental_install` to restore.

- `emilkowalski/skills`: web design, animation, motion review and mobile polish.
- `anthropics/skills`: frontend design, Playwright testing, documentation and skills.
- `apollographql/skills`: Rust best practices.
- `astrolicious/agent-skills`: Astro, with current official documentation lookup.
- `khmm12/solidjs-v2-skills`: Solid 2 implementation and review. This is a small
  community source; verify against installed RC typings and official v2 docs.

Only relevant skills were selected; unrelated platform and artifact skills were
omitted. Repository instructions and pinned dependency versions take precedence.

Repository license texts are retained in `third-party-licenses/`; skill-specific
license files and notices take precedence where supplied.
