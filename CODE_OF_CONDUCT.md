# Code of conduct

Be respectful and constructive. Welcome different backgrounds and experience;
criticize ideas and code without attacking people. Harassment, discrimination,
threats, sexual harassment, doxxing and deliberate disruption are unacceptable.

These standards apply to project spaces and representation of the project.
Maintainers may edit or remove content, close discussions, or restrict access
based on severity and repeated behavior. Maintainers follow the same standards.

Report ordinary conduct concerns through
[GitHub Issues](https://github.com/hexvale-labs/condite/issues), without posting
private information. For sensitive conduct reports, use GitHub's
[Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature. That private channel goes to GitHub, not directly to this project's
maintainers; GitHub has no general private conduct inbox for repository owners.
