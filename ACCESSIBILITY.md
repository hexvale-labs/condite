# Accessibility

Condite aims to support keyboard navigation, visible focus, reduced motion,
responsive layouts and right-to-left languages. Dashboard browser checks include
automated accessibility checks and dialog/focus workflows; these do not establish
complete WCAG conformance or replace assistive-technology testing.

Report barriers through [GitHub Issues](https://github.com/hexvale-labs/condite/issues).
Include the affected client/page, operating system, browser or Discord/Vencord
version, assistive technology and reproduction steps. Omit private file links.

Live Discord integration, screen-reader coverage and real-device touch behavior
need continuing manual verification. Maintainers prioritize barriers that prevent
uploading, managing links or changing retention.
