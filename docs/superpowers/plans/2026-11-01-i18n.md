# Shared client translations

Goal: support English and the 19 requested languages in the dashboard and Condite's Vencord/Vesktop interface.

Approved approach: one dependency-free shared catalog, complete dictionaries checked against English, native language names, Arabic RTL. Use Simplified Chinese, Brazilian Portuguese and Norwegian Bokmål. Preserve SDK license boundaries; catalogs are MIT and copied into Vencord by its existing sync tool.

Implementation:
- Extract dashboard messages into `clients/i18n`, with one dictionary per locale and shared locale resolution.
- Add complete translations authored directly, key parity checks and locale alias tests.
- Connect Astro routing and a compact accessible language selector; set document direction.
- Copy shared resources during Vencord sync; localize plugin UI and follow Discord's language.
- Validate both clients with available checks. Document unsupported live-client verification.

Review focus: regional aliases, Arabic direction, long labels, no-JS language selection, u64 formatting, missing translation keys, copied catalog freshness.

Validation: dashboard check/build and seven unit/catalog tests pass; all 12
browser tests pass in production and development. All 18 plugin tests and both
native/web builds pass. Vencord source type checking passes with
`--skipLibCheck`; the unmodified full check reports conflicting Electron types
from the root workspace and pinned checkout. Live Discord/Vesktop and physical
device testing remain outstanding.
