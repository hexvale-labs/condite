# Security policy

Report suspected vulnerabilities using
[GitHub private vulnerability reporting](https://github.com/hexvale-labs/condite/security/advisories/new).
Do not publish exploit details or sensitive data in an issue. Include affected
versions, impact and minimal reproduction steps with example credentials only.

If the private report form is unavailable, open a GitHub issue asking maintainers
to enable private reporting, without describing the vulnerability. All security
communication stays on GitHub. No response-time guarantee is offered.

Security fixes target the current default branch. Deployments should use the
latest reviewed version and keep private storage inaccessible anonymously.
