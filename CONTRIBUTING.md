# Contributing

Use [GitHub Issues](https://github.com/hexvale-labs/condite/issues) for bugs,
questions and feature proposals. Search existing issues first. Report security
concerns [privately](https://github.com/hexvale-labs/condite/security/advisories/new).
Do not include credentials, private file URLs or personal uploads in reports.

Read [development guidance](docs/development.md) and the applicable `AGENTS.md`.
Keep changes focused, update affected clients/SDKs with API changes, and run the
component's documented checks. Describe behavior, verification and limitations in
your pull request. Respect each component's license and the
[code of conduct](CODE_OF_CONDUCT.md).

AI-assisted contributions are welcome. Disclose substantial generated work and
review it before submitting; contributors remain responsible for their changes.
