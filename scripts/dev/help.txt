Condite development — run these from the repository root

First time:
  just install             Install all components and the mprocs runner
  just check tools         Find missing tools/configuration (read-only)
  Edit crates/condite-core/.env with your database and S3 settings.
  just run                 Start API (:8080) + dashboard (:4321) in one terminal
  Open http://localhost:4321/en/ (or /es/).

Everyday commands (omitting a target means all):
  just install [backend|dashboard|vencord|sdk|runner|all]
  just build   [backend|dashboard|vencord|sdk|all]
  just run     [backend|dashboard|all]
  just check   [rust|backend|dashboard|vencord|sdk|wasm|all]
  just check tools [backend|dashboard|sdk|vencord|all]
  just migrate NAME        Generate a database migration for review

Examples:
  just install dashboard   Install workspace deps and build SDKs for the UI
  just run backend         Run only the API
  just build sdk           Regenerate shared types and native/browser packages
  just check rust          Format check, Clippy, and tests across the workspace
  just check wasm          Clippy for browser-only Rust
  just check tools backend Check backend tools and required environment keys
  just install runner      Install mprocs independently

mprocs: select a process with arrows; r restarts it; Ctrl-a focuses the process list; q quits all processes (confirm if prompted).
The backend still needs a reachable database and S3 bucket; neither is started here.
SDKs are libraries. Vencord runs inside Discord: build it, inject it, and restart
Discord following clients/vencord-extension/README.md. Neither has a dev server.
Vencord installation requires Git, Node 22+ and pnpm 12.15.0.
Build all includes Vencord; run all starts only the backend and dashboard.
Dashboard checks include unit tests and production/development browser tests.

Component directories also provide just help, install, build, and check;
backend/dashboard provide run. Local checks accept tools for setup diagnostics.
See docs/development.md for details and component README links.
